Postgres vs Weaviate

The same 5,300 chunks and the same Titan vectors, searched two ways. Compare which chunks each engine ranks highest for one question across all papers.

Retrieval labChat

Postgres (Neon)

Three steps we wrote ourselves: BM25 in SQL over a word-count table (rag_terms), pgvector nearest neighbours (HNSW, cosine), then Reciprocal Rank Fusion of the two top-25 lists (equal weight).

Weaviate

One hybrid query: native BM25 plus vector search (HFresh index, cosine), fused inside the engine. alpha sets the balance (0 = keyword only, 1 = vector only); fusion chooses rank-based or normalised-score blending.
